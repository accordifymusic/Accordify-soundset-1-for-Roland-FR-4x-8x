# Accordify Soundset #1 for Roland FR-4x / FR-8x

**An acoustic accordion soundset inspired by two real Italian accordions from Castelfidardo, Italy.**

Accordify Soundset #1 is designed for the Roland FR-4x and FR-8x digital accordions, bringing the character and expression of traditional acoustic instruments into the digital accordion environment.

The soundset is based on two acoustic accordions from Castelfidardo, featuring **4/5 and 5/5 reed configurations**.

## 🎹 Soundset Features

- **14 right-hand (treble) registers**
- **7 left-hand (bass) registers**
- Sound character based on two acoustic Italian accordions from Castelfidardo
- 4/5 and 5/5 reed configurations represented in the sound design
- Designed for expressive playing and a natural acoustic accordion character
- Compatible with Roland FR-4x and FR-8x digital accordions

- Roland FR-8x

## 📥 Installation

There are two recommended ways to install the soundset.

### Method 1: USB Flash Drive

1. Download the soundset file for your Roland accordion.
2. Copy the file to a compatible USB flash drive.
3. Connect the USB drive to your accordion.
4. Use the instrument's soundset or data management functions to load the file.
5. Save or store the soundset in the appropriate user memory location, if required.

### Method 2: USB Connection via Computer

1. Connect your Roland FR-4x or FR-8x to a PC or Mac using a USB cable.
2. Launch the appropriate Roland Editor software.
3. Import the soundset file, following the editor's supported workflow.
4. Transfer the soundset to your accordion.
5. Store it in the appropriate user memory location.

**Important:** Installation procedures may differ between the FR-4x and FR-8x. Consult the official Roland owner's manual and editor documentation for detailed instructions on USB connections, importing data, and saving user settings.
